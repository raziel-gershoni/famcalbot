# CLAUDE.md

Rules for coding agents in this repo. Setup, env vars and deployment are in README.md.

- Never replace `ENCRYPTION_KEY` without setting `ENCRYPTION_KEY_PREVIOUS` to the old value in the same deploy, and remove `ENCRYPTION_KEY_PREVIOUS` only after the key sweep logs `[key-sweep] SAFE` (README, "Rotating `ENCRYPTION_KEY`").
- Turn a wall time into an instant only with `wallTimeToInstant` (`src/utils/wall-time.ts`, re-exported by `calendar-write/walltime.ts`): a time the clocks skip moves forward by the jump, a repeated one is its first occurrence, whatever zone the server runs in. Never `fromZonedTime`, and never move a `Date` by its local fields (`setHours`, `setDate`, `setSeconds`, ...): both depend on the server's zone, so use epoch arithmetic (`new Date(Date.now() - 24 * 60 * 60 * 1000)`) or the resolver. Read a zone's clock for logic with `instantToWallTime` (`src/utils/wall-time.ts`); `formatInTimeZone` is display-only, because it reads an hour late in the server's own skipped hour. `scripts/smoke-dst.ts` fails on the first two (it re-runs itself under three process zones).
- A send to a person that no one asked for (a cron pass, a nudge, a notice) asks `isPaused(user, at, '<kind>')` (`src/services/zmanim/pause.ts`, the Shabbat and Yom Tov pause) before it sends (the third argument names the send, and a paused one logs `[pause] skipped <kind> for <userId>`). Replies to the person's own actions and messages to the admin do not. `scripts/smoke-pause.ts` lists every file that sends and fails on one nobody classified, so a new sender is added to its `PAUSED` or `NOT_PAUSED` table with the reason.
- A reminder by zman (`NativeEvent.zmanSpec`, date-only) is due at its zman at each recipient's own place. Every reader gets a reminder's due time from `dueAtForOccurrence` / `reminderDueAt` (`src/services/native-reminders/due.ts`) given the person's `ZmanClock` (`zmanClockFor` in `src/services/zmanim/reminder-clock.ts`, which asks `zmanInstant` and nothing else): the pass, the home, the digests and the summaries. Never store the computed time in `startsAt`, never count a zman anywhere else, and never import `src/services/zmanim` into a `'use client'` file: the Mini App gets the times in the DTO, in the editor info and in the sun sheet's list (`GET /api/zmanim`, `zmanDayList` in `src/services/zmanim/reminder-times.ts`). The list shares the editor info's rows (`zmanRows`), and its candle lighting and end of Shabbat or Yom Tov come from `shabbatYomTovWindows`, the windows the pause reads, so the list and the pause never disagree.
