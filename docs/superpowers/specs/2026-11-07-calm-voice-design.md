## 1. Goal
Let a person swap the two-host radio show for one calm presenter who reads the same summary. The show stays as it is for everyone who keeps it.

## 2. What the person sees
- **Settings (Mini App and web), Summaries card**, right under the "Voice summary" switch, shown only while that switch is on (and, like the switch, hidden for an account with no chat). It is a closed-set `ValueRow`, like "Address me as":
  - en: **Voice style**: "Radio show, two hosts" / "Calm, one voice"
  - he: **סגנון הקול**: "תוכנית רדיו, שני מגישים" / "קול אחד רגוע"
  - ru: **Стиль озвучки**: "Радиошоу с двумя ведущими" / "Один спокойный голос"
  - The switch's hint stops saying "two hosts", because the row below now says it: en "Your summary as a short voice note", he "הסיכום כהודעה קולית קצרה", ru "Сводка в виде короткого голосового сообщения". All of it is gender-neutral Hebrew, with no emoji. The wording goes through a native-ear check before ship.
- **What calm sounds like:** one presenter at an even, warm radio pace, with no banter, no hand-offs, no "yalla", no sounds and no mood swings. The content is the same as the show's: the greeting from the summary, the date, the weather with one tip, every event with its time in words, the kids, birthdays, reminders and the week ahead. It runs about as long as the show (roughly 45-60 s) and ends with a quiet sign-off. Evening, weekly and weather notes get the same voice in the same calm tone.

## 3. Decisions (my recommendation first)
1. **Default: the show stays the default for everyone, existing and new accounts.** The owner called calm an "alternative", and switching people over silently would change something many of them like.
2. **One calm voice per language, with no female/male choice for the listener.** The owner chose a **male** voice (2026-11-07) and picks which male voice by ear in a blind round (section 4). This matches the rule "no extra settings beyond the one choice".
3. **Covers every summary voice note:** morning (daily), evening (tomorrow), /lookahead and /nextweek (weekly) and /weather. All of them already pass through the one branch, `produceVoice` → `produceShowVoice`. Spoken CRUD replies (`speakOutcome`) stay as they are: one short line in the anchor voice, behind an admin flag that is off by default.
4. **The Settings screen is the only place to make the choice.** There is no bot command: the bot has no /settings command, and settings live in the Mini App. WhatsApp voice notes follow the same field, because they use the same pipeline.
5. **Same length and same content as the show, not the shorter old narrator length.** The feedback was about intensity, not length.
6. **Marketing and bot copy stay unchanged** (the welcome value prop, the site features, the bot's "show" line). They remain true while the show is the default. The legal texts are not touched, because they describe voice only in general terms.

### Technical choices (no product decision needed)
- **Data:** a new column `User.voiceFormat String @default("show")`, closed set `'show' | 'calm'`, narrowed in `UserConfig` the way `gender` is. Migration `prisma/migrations/20261106000000_voice_format`. The name is not on `smoke-dead-columns`' list (`voicePreference` and `voiceStyle` are dead and must not come back). It is added to the account-merge defaults in `src/services/account-linking.ts:122`. Voice reads the user row at send time, so no cache needs syncing.
- **One pipeline with a mode, not a copy:** `ShowFormat = 'show' | 'calm'` goes on `ShowPromptContext` (set by `buildShowContext` from `user.voiceFormat`; a missing or unknown value means show). The same `writeShowScript` path, the same `generateAICompletion` call, the same `AI_MODEL` and the same MEDIUM thinking level, with regenerate-once.
- **Prompts per language:** new files `src/prompts/voice-show/calm-{he,en,ru}.ts`, with `index.ts` dispatching by format. The facts rules (each kind's content, times and numbers in words, midnight, birthdays, reminders, no invented facts, the user's rules, family gender lines) are shared from each language's show module through a `format` argument to `kindRules`. Calm swaps only the energy lines: "celebrate a free day" becomes "say calmly the calendar is free", and the energetic close becomes a quiet sign-off. The Hebrew calm prompt carries the show's pointing rules word for word: the writer points subject-gendered words (מְחַכֶּה/מְחַכָּה by subject, also for the presenter speaking of themself), תּוֹרֵךְ, אַתְּ. The code still runs `pointHebrewTimes` and `pointSecondPerson`. Russian keeps the "ты" and unknown-gender rules. The presenter's gender (from the voice table) sets how they speak of themself in he/ru.
- **Show bytes pinned:** before the refactor, a golden fixture records every show prompt for a matrix (he/en/ru × 4 kinds × listener gender × culture × with/without ⏰) and every show TTS request (voice, text, style) from a fake run. After the change both must match byte for byte.
- **Script:** the same parser, `parseShowScript(raw, source, format)`. Calm schema: `{"turns":[{"text":"..."}]}` with paragraphs as turns. The host is always A and the mood is unused. 2-12 paragraphs of up to 400 chars each. The "both hosts" check is skipped. No sound tags at all: every tag is stripped (a `<yawn>`-type tag also slows the whole read). The cleanup is the same (stage directions, labels, HTML, emoji, digit warnings).
- **Voice and style:** a `CALM_VOICES` table next to `SHOW_VOICES` in `voice-generator.ts`, `{ he|en|ru: { voice, gender } }`, built-in voices only. `generateShowVoice` takes a cast: show `{A,B}` exactly as today, or calm `{A: voice}`. It keeps the same semaphore, 90 s deadline, `synthesizeDialogue` retries and `mixDialogue` (one speaker; `gapMs` about 400 between paragraphs, tuned in the round; the show passes nothing, so it is unchanged). One constant goes on every calm paragraph: **`CALM_STYLE = 'calm, warm radio presenter'`**. The tempo lesson applies: the style string is the persona, so it is identical on every line, never gets a mood colour and has no pace word ("slowly" ran ~40% slower). It does not say "morning", because evening notes use it too. Because the style changes the timbre, the voice is picked by ear WITH this exact string, and the string is frozen after the round; changing it later means listening again.
- **Caption (admin only):** `formatShowCaption` prints `calm A:<voice>` with no B.
- **Files touched:** `prisma/schema.prisma` + migration; `src/types.ts`; `src/services/account-linking.ts`; `app/api/settings/route.ts` (`isVoiceFormat`, 400 on anything else); `app/[locale]/(app)/settings/{SettingsClient.tsx,settings-body.ts}`; `src/lib/page-data.ts`; `messages/{en,he,ru}.json` (`settings.voice.hint`, `settings.voiceFormat.{label,show,calm}`); `src/services/voice-show/{types.ts,context.ts,script.ts,produce.ts}`; `src/prompts/voice-show/{index.ts,types.ts,he.ts,en.ts,ru.ts,calm-he.ts,calm-en.ts,calm-ru.ts}`; `src/services/voice-generator.ts`; `src/utils/ai-footer.ts`; `scripts/eval-voice-show.ts` (`--format calm`, paid, run only after your OK); README (the stale "selectable voices and styles" line, README.md:28); the spec under `docs/superpowers/specs/`.
- **Tests (all mocked, offline):** a new `scripts/smoke-voice-calm.ts` covering the show prompt and TTS-request goldens; calm prompt rules (content rules present, presenter gender line, no moods or sounds, Hebrew pointing rule); the calm parser (rejects host B, strips every tag, enforces paragraph bounds); calm lines (one voice, CALM_STYLE everywhere, Hebrew pointing applied); routing (`voiceFormat` missing → show, 'calm' → calm); the caption. Existing smokes extended: `smoke-settings-render` (S3 body with `voiceFormat`, S10 keys in all three languages), a settings API case (invalid → 400, 'calm' saved), `smoke-voice-limits` (calm counted once, like the show), `smoke-voice-show-produce/-writer` (show unchanged). `smoke-dead-columns` must still pass. Gate: `npx tsc --noEmit && npx next build` plus the repo smokes. Never the migrating build script.

## 4. Listening round (paid; needs your estimate OK first)
**Method:** you pick blind, by ear (LLM judges saturate), from m4a clips. Each clip is made the way production will make it: one TTS request per paragraph on `gemini-3.8-flash-tts` with `CALM_STYLE`, mixed with the same gap, then ffmpeg to m4a. A free offline check (parselmouth) measures per-paragraph pitch and letters/s. The target is the show's own bar: within 8% pace and 3 semitones across paragraphs, i.e. one steady person.

**Candidates per language (the same built-ins for he, en and ru; the owner chose male, so only the four male ones are sampled):**
- Female (not sampled after the owner chose male): Sulafat, Vindemiatrix, Achernar, Despina.
- Male: Umbriel (Easy-going), Achird (Friendly), Iapetus (Clear), Charon (Informative).
- Left out: Schedar and Puck (the show's hosts, so calm would sound like the show), Algieba (your weakest Hebrew male), the upbeat ones (Fenrir, Sadachbia, Laomedeia), the firm ones (Kore, Orus, Alnilam) and Enceladus (breathy, risky in Hebrew).
- **Blind pairs (names hidden, order shuffled):** round 1 is Umbriel–Achird and Iapetus–Charon. The final is the two winners, which gives one voice per language. The final reuses the clips, so it costs nothing.

**Sample text (hand-written, so no writer call; the date is illustrative; male listener, so no pointing needed for him; the presenter never speaks of themself, so one text works for both genders; the text is shown as TTS receives it, after pointing):**
