## Global Constraints

- No inline user-facing strings: every new text goes in `messages/{en,he,ru}.json`, and the three files keep the same keys (`scripts/check-i18n-parity.ts` must pass; "the parity smoke" below means this script).
- Hebrew addresses the person gender-neutrally: plural imperative in sentences ("נסו שוב", "שלחו"), infinitive or a noun on buttons ("לפתוח הגדרות", "פתיחת הגדרות"), never "את/ה", "ספר/י" or any slash form. The bot may still speak of itself in the masculine ("לא הצלחתי", "אני לא בטוח").
- Russian is formal ("вы", "Попробуйте"). The bot's own past tense stays masculine, as today ("Я услышал").
- Hebrew and Russian read as written in that language, not translated word for word.
- Every caught error is logged (`console.error` with a `[tag]`) and, where the file already uses it, sent to `captureError`. No empty catch.
- Never swap `user.id` and `telegramId`. A Telegram callback's `chatId` in a private chat is the person's Telegram id.
- A send no one asked for asks `isPaused` first (CLAUDE.md). Replies to a person's own message do not.
- Smokes run with fake env only: `bash <S>/run-smoke.sh scripts/smoke-<name>.ts`. Never `npm run build`; type-check with `npx tsc --noEmit`, lint with `npx eslint <files>`.
- A smoke proves a fix only once it has been seen to FAIL with the fix reverted (mutation check). Report each mutation result.
- Commit after each numbered fix, message `fix(<area>): <what the person now sees>`, ending with the two attribution lines:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_017Qxen88HvHhmznBZG7Yo31`.
- Never push. Never touch `.env*` or print secrets.
- `BotMessages` below means `Awaited<ReturnType<typeof getBotMessages>>` (`src/lib/bot-messages.ts`); export it under that name from there if no such type exists.
